LockPast the payment deadline, the record locks itself. Not a reminder, not a colour change — the row stops being editable until someone with the right role clears it. The same reasoning as a refusal threshold: a prompt can be ignored, a lock cannot.

Reading this honestly

  • This is a reconstruction. The real application needs accounting-system OAuth credentials, and starts empty because it persists to a file.
  • Architecturally this is the least serious application in the set, and that is the point of including it.
  • Read it next to the Billing API demo. “I built this, hit its limits, and rebuilt it properly” is a better answer than either app alone.
