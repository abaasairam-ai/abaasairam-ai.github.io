LockPast the payment deadline, the record locks itself. Not a reminder, not a colour change — the row stops being editable until someone with the right role clears it. Same reasoning as a refusal threshold: a prompt can be ignored, a lock cannot.
HistoryThis is the first version, kept on purpose. Persistence is a JSON file. It worked until it did not. The Billing API is what replaced it — and shown together, the pair says more than either does alone.
