Asset register — public form, admin view

A record of which employee holds which device, so offboarding stops being guesswork. Employees self-register through a public form; admins search and export behind a sign-in. Runs fully offline.

What is real here

  • The two-sided design — public registration, authenticated admin
  • The form fields and the admin table columns
  • Excel and CSV export, and the dashboard breakdown
  • That it runs entirely offline

What is invented

  • All employee initials, serials and models
  • Every count and date
  • The three unreturned devices
