Demos — not real screens

Every page linked below is a rebuilt copy of an interface, drawn with that application's own design tokens. Each one is a rebuild and not a screenshot, and none is connected to anything. All data on them is invented — no real client, vendor, employee, tax identifier or amount appears anywhere. The production systems run against live accounting, GST-portal and TRACES data, and none of that data has been published or exported.

Why rebuilt screens rather than screenshots

  • A screenshot taken from a running instance contains real client names, tax identifiers and amounts — baked into pixels, where they cannot be searched for or scrubbed.
  • These pages had no real data in them to begin with, so there is nothing to leak. Each one names what is real (the layout, the columns, the logic, the controls) and what was invented (every name, identifier, amount and date).
  • Why the repositories are private. This code was built in a finance role and belongs to that context, so it is not published openly. Access can be granted on request for anyone assessing the work — ask and it will be arranged.
  • Identifiers follow the same dummy conventions as the scrubbed code — placeholder client codes and the AAAA00001A tax-identifier pattern — so nothing here can be mistaken for the real thing.
