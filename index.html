Private Tax Knowledge Assistant

In progress

A retrieval system over the complete Income-tax Act, 2025 and Income-tax Rules, 2026 — 1,088 pages of primary law, parsed and split into 1,505 citation-tagged chunks with 100% section coverage, verified against the official numbering.

Parsing an Act turns out to be the hard part. The source PDF fights you: sections formatted as 443.9[***] or 94 . (1), slab tables whose rows look exactly like section starts, and footnotes numbered 1–99 that hijack the sequence entirely. Pattern-matching alone found 868 "sections" where there are 536. The fix was to require three things at once — the number continues the sequence, it sits near the previous section, and a real heading precedes it.

Designed to run fully local — documents, embeddings and model all on-machine — so confidential client data never leaves the device.

Universal Document Chunker

Live · try it

A document-agnostic tool that splits PDFs, Word files, Markdown and text into retrieval-ready chunks for any RAG pipeline — at real structural boundaries, never mid-sentence. Available as a Python CLI and as a drag-and-drop browser tool.

Its useful trick is that structure detection is scored, not first-match. An early version latched onto lines beginning "Section 515(3)(b)…" — which were cross-references inside sentences, not headings — and shredded the document. It now generates every candidate structure and ranks them, penalising both over-matching (the same heading recurring dozens of times) and under-matching (6 headings across 422 pages). On the same file that moved detection from 6 useless blocks to 210 correct ones.

Detects scanned PDFs and flags them for OCR rather than emitting unusable text. The browser version processes files client-side with no upload, so it is safe to point at confidential documents.
