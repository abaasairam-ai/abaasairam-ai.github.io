05Background

About

I'm Sairam, a financial accountant in Hyderabad, India, leading a team of four across full-cycle accounting, payroll, GST/TDS, audits and regulatory filings — CA (Inter) qualified.

What sets my work apart is that I don't just run finance processes — I automate them. Self-taught in Python and AI tooling, I build my own tools rather than buying software: JSON generators for tax filings, reconciliation engines, document-parsing pipelines, and private AI assistants that keep sensitive data in-house.

I care about the unglamorous part. Most AI-in-finance demos fall over on real documents — a table split across pages, a section number formatted inconsistently, a confident answer with no citation. Getting those right is the actual work.

How these are built: I write the code with Claude as a pair programmer. The engineering judgement is mine — what to build, where the guardrail belongs, what the eval set should test, when to distrust a result that looks fine — and I measure rather than assume. Worth saying plainly rather than leaving it implied: the skill here isn't recalling syntax, it's knowing what to build and being able to tell when it's wrong.

It's where a finance background beats a purely technical one: I know what a wrong number costs. — On building AI for finance
